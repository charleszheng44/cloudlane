Run on this Omarchy laptop using system Qt 6.11.2, libmpv 0.41, OpenSSL 3.6, SQLite, TagLib and Secret Service. All checks below passed after the fixes described here.

| 7 transport checks | Independent EAPI/form fixtures; WEAPI CBC/RSA padding; encrypted/gzip response decoding; malformed ciphertext rejection |
| 8 model checks | Duplicate queue identities, reorder, shuffle history, lyric timing/translation, typed episode/comment IDs |
| 10 action checks | Stale navigation/playback responses, null/trial grants, QR refresh, logout, comment target isolation, paused FM/video restoration, cache selection |
| SQLite/local-library checks | Cache separation by account key; stale timestamp; local-library persistence |
| Download checks | Local HTTP fixture, complete file byte equality, account isolation, integrity failure, retry when the server ignores Range, no signed URL persisted |
| Desktop media interface | Real session D-Bus GetAll, metadata typing, microsecond duration, Next dispatch and Volume write |
| Native video/audio | Generated local test video rendered through libmpv OpenGL; pause, seek and position progression |
| Native UI | Real Wayland window at 1100×760 and 640×480; queue panel open/close; no QML runtime warnings in these flows |
| Anonymous NetEase transport | Real search returned 50 tracks in the UI; separate native probe retrieved a QR challenge and an XEAPI response. The anonymous stream response contained no URL |
| Design preview | Earlier 30 focused HTML-preview checks; these are separate from production native-app checks |

The native test temporarily floats only its own process window under Hyprland so the requested test dimensions are respected. It captures its own window, not the desktop. It does not change persistent compositor configuration. [Hyprland dispatcher contract](https://wiki.hypr.land/configuring/core/dispatchers/).

Fixes caught by testing included Qt sequence conversion into JavaScript arrays, a nullable SQLite error field, and invalid absent metadata values sent over D-Bus. The last issue aborted the isolated MPRIS test; the coredump identified MprisPlayer::changed → QtDBus/libdbus marshalling. Metadata now uses valid typed strings and the same regression test passes. No user account or music data was involved in that test.

The graphics driver probe prints `Cannot load libcuda.so.1` on this machine, then succeeds with the available graphics stack. This was not a playback or rendering failure.

## Not proven

No NetEase account login was completed during this run. Account-library payloads, entitled streaming/download grants, writes, cloud and subscription operations still need real-account acceptance tests. Download tests prove the local download engine, not NetEase account rights. Native video tests prove rendering of a local video, not availability of a particular online MV.

Large-font accessibility, protected offline media, Together, cloud upload, creator publishing and other outstanding parity work remain in [IMPLEMENTATION.md](../IMPLEMENTATION.md). This build is a development preview.

## Reproduce

```sh
scripts/check.sh
YUNJIAN_NATIVE_TESTS=1 YUNJIAN_LIVE_TESTS=1 scripts/check.sh
```

Development tests also need Node, FFmpeg and a D-Bus session. The second command opens an isolated native test window and performs a read-only public search. It uses generated media and temporary account settings. Neither Node nor FFmpeg is an application runtime dependency.
